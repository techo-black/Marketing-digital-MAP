# Marketing Digital Mind Map

Mapa mental interativo feito com HTML, CSS e JavaScript puro.

## Como usar

1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Arraste os blocos.
4. Clique em "Editar" para alterar qualquer etapa.
5. Clique em "＋ Novo bloco" para criar novas etapas.
6. Clique em "↗ Conectar" e depois em dois blocos para criar uma ligação.
7. Use "↓ Exportar mapa" para guardar seu mapa em JSON.
8. Use "↑ Importar mapa" para carregar um mapa salvo.

## Estrutura

- `index.html` — interface
- `style.css` — design
- `script.js` — lógica do mapa

Não precisa de servidor, Node.js ou banco de dados para executar a versão básica.
